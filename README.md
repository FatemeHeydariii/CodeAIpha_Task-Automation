# JPG File Automation

A simple Python automation script that finds all .jpg files in a folder and moves them to another folder automatically.

## Features

- Checks a source folder for files.
- Finds .jpg files automatically.
- Creates the destination folder if it does not exist.
- Moves JPG files using Python.
- Displays the files that were moved.

## How to Run

Create a folder named photos next to the Python script and put some .jpg files inside it.

Then run:

python main.py

The JPG files will be moved to the jpg_files folder.
